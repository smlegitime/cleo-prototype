Can we have one label that's a positive badge and another that's a warning?

[2026-03-12 05:31] AI Assistant
Yes, absolutely! You can mix both types in the same labeler.

For the **positive badge** (like verification or quality indicator):
- Set `blurs` to `"none"` so it doesn't hide anything
- Set `severity` to `"inform"` (just informational)
- Set `defaultSetting` to `"ignore"` so users see it without any filtering

For the **warning label**:
- Set `blurs` to `"content"` or `"media"` to blur what's flagged
- Set `severity` to `"alert"` or `"inform"`
- Set `defaultSetting` to `"warn"` or `"hide"` to notify users or hide by default

Here's a working example:

```json
{
  "labels": [
    {
      "identifier": "verified-creator",
      "severity": "inform",
      "blurs": "none",
      "defaultSetting": "ignore",
      "locales": [
        {
          "lang": "en",
          "name": "Verified Creator",
          "description": "This account is a verified content creator"
        }
      ]
    },
    {
      "identifier": "potential-spam",
      "severity": "alert",
      "blurs": "content",
      "defaultSetting": "warn",
      "locales": [
        {
          "lang": "en",
          "name": "Potential Spam",
          "description": "This content may be spam"
        }
      ]
    }
  ]
}
```
